# ReCalc

記録して再利用できる、大きな表示の関数電卓。ブラウザだけで動きます（インストール・ビルド不要、依存ゼロ）。

**公開ページ：https://nice-rich-2030.github.io/recalc/**

## 使い方

- [公開ページ](https://nice-rich-2030.github.io/recalc/) を開く（またはダウンロードした `index.html` をダブルクリック）
- 式をそのまま打って `Enter`。打っている途中の結果が薄く見えます
- 計算はすべて右の記録に残ります。`#1`（直前の結果）`#2`（2つ前）… や `ans` で前の結果を使えます
- 記録の結果・式・番号をクリックすると、入力欄に入ります
- 空欄で `* / + ^` を打つと、先頭に `ans` が付きます
- `⌘C` / `Ctrl+C`（文字を選んでいないとき）で結果をコピー。貼り付けた `1,234,567` や全角数字は自動で直します
- 記録は「JSON に保存」で書き出し、別のパソコン・ブラウザで「読み込む」と移せます。「CSV に保存」は Excel 用
- `F1` または「使い方」でキー操作の一覧

記録はブラウザの localStorage に保存されます（最大 1000 件、ブラウザごと・端末ごとに別）。

## 開発

```sh
npm test    # 計算部分のテスト（node --test。依存なし）
```

| ファイル | 役割 |
|----------|------|
| `index.html` | 画面の骨組み（メイン画面・ヘルプ） |
| `css/style.css` | デザイン一式 |
| `js/calc.js` | 構文解析と計算（`eval` 不使用） |
| `js/normalize.js` | 貼り付け・入力文字の整形 |
| `js/format.js` | 数値の表示用整形（有効数字 12 桁・3桁区切り・指数表記） |
| `js/store.js` | 記録・設定の保存、JSON / CSV の書き出し・読み込み |
| `js/app.js` | 画面の操作・キー操作・クリップボード |
| `test/` | `node --test` のテスト |

- ES モジュールは使わず `<script defer>` で読み込むので、`file://` で開いても動きます
- URL に `?debug=1` を付けると、字句分割と構文木、コピーの経路をコンソールに出します
- 仕様書：`SPEC.md` / `SPEC_DETAIL.md` / `SPEC_VALIDATION.md`、実装計画：`PLAN.md`、モック：`mocks/`
